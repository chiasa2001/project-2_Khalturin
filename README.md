## Управление таблицами

В системе реализована базовая логика управления таблицами через консольные команды.

### Доступные команды

- `create_table <имя_таблицы> <столбец:тип> [столбец:тип]...`  
  Создаёт новую таблицу. Автоматически добавляет столбец `ID:int` в начало.  
  Поддерживаемые типы: `int`, `str`, `bool`.  
  Пример: `create_table users name:str age:int is_active:bool`

- `drop_table <имя_таблицы>`  
  Удаляет таблицу из метаданных.  
  Пример: `drop_table users`

- `exit`  
  Завершает работу программы.

### Хранение метаданных

Вся информация о структуре таблиц хранится в файле `db_meta.json` в корне проекта.
